# Proyecto de Base de Datos de Fórmula 1

## Descripción

Proyecto académico de diseño e implementación de una base de datos relacional para la gestión de información relacionada con el campeonato de Fórmula 1.

El sistema permite organizar y gestionar información del campeonato mediante un modelo relacional, utilizando PostgreSQL como sistema gestor de bases de datos y SQL para la definición y manipulación de los datos. También se emplea Python como herramienta de apoyo.

## Tecnologías utilizadas

- **PostgreSQL:** sistema gestor de bases de datos relacionales.
- **SQL:** creación, consulta y manipulación de datos.
- **Python:** desarrollo de scripts y procesamiento de información.

## Contenidos del proyecto

El repositorio contiene los archivos correspondientes al desarrollo del proyecto, organizados en la carpeta `BBDD_2025`.

## Objetivos académicos

- Diseñar e implementar una base de datos relacional.
- Definir estructuras y relaciones entre las distintas entidades.
- Trabajar con consultas SQL para la gestión de información.
- Utilizar PostgreSQL para implementar y administrar la base de datos.
- Aplicar Python como herramienta complementaria.

## Contexto

Proyecto realizado en el ámbito de la asignatura de Bases de Datos del Grado en Ingeniería de Computadores de la Universidad de Alcalá.
